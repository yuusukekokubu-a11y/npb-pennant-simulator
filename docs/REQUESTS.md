# 要望リスト

画面や機能についての要望の控えです(D-139)。壁打ち側が依頼文に入れ、Code が記録します。
画面のデザインの見直しは、機能の実装が一通り終わってから、まとめて行います(時期は改めて相談)。

## 対応済み
| 要望 | 対応した依頼 |
| --- | --- |
| BABIP の倍率の範囲(0.97〜1.03)を広げるか | 第3弾①の依頼で「据え置き」と決定(D-153) |
| 「止める」ボタンの出し方(短い処理では出さない。0.6 秒を超えたときだけ) | 最小のブラウザ画面②(D-118) |
| OPS を「基本」に移す | 個人成績の手直し(D-130) |
| 並び順の保持(基本・セイバー・能力を切り替えても保つ) | 個人成績の手直し(D-131) |
| FA・ドラフト・市場の表の作り直し(判断に使う列を左に、絞り込み 1 本、自球団の状況が見える) | UI の整理①b(D-296〜D-299) |
| 市場を指名の順番(ウェーバー)から、FA と同じ提示の方式に | UI の整理①b(D-300) |
| 契約の画面の「状態」「今回の提示」を WAR の右へ、「この段階をおまかせ」の確認(ドラフトと FA だけ) | UI の整理①b(D-284) |
| 並び順の指標の固定表示(表にない指標は名前の隣に固定して出す) | 個人成績の手直し(D-131) |
| 成績の説明を表の下に置く(表を上、説明を下) | UI の整理②で置き換え:説明は画面から外し、メニューの用語集にまとめる(D-306) |
| 説明が多く、表や操作が押し下げられる | UI の整理②(用語集・1 行の注意書き・新規開始の説明バー。D-306〜D-313) |

## デザインの見直しのときに対応
| 要望 | 補足 |
| --- | --- |
| 固定の列の名前の幅の確認 | 今は名前の列を 9em に固定している(個人成績の手直し) |
| 既存の表(個人成績・チーム・順位)の広い画面への対応と、左右に分ける画面構成(第 2 段階) | D-223。画像つきの案を出す |
| 総合のふれ幅の見せ方(2 層化で広がった ±5 前後のふれ幅で、評価の使いやすさが保たれているか) | 評価の 2 層化(D-212、D-213)。ドラフトの画面と選手のページ |
| 色・文字・余白の値を一か所(CSS の変数)にまとめ、既存の画面を置き換える | F3-2 以降は新しく作る部分だけ変数で指定(D-239)。現状は docs/design/INVENTORY.md |
| 横画面の余白がさみしい | D-269。見直しの段階 1 で画像つきの案を並べる |
| 全体に柔らかい印象にしたい | D-269。同上 |
| 列の区切りの縦線と桁のそろえ(縦線がないと数字が見にくい) | D-269。同上。固定列の幅のずれ自体は D-267 で修正済み |
| 並べ替えた列の数値が ▲▼ の余白の分だけ左に寄る | D-276。縦線の案と一緒に決める |

## 候補(時期は未定。球団職員・盗塁等・年度の確定の取り消しは、デザインの見直しの後に必要になったら行う。D-241)
| 要望 | 補足 |
| --- | --- |
| 個人成績の「すべて」のタブ | 基本とセイバーをまとめて見る |
| 盗塁・暴投・捕逸の導入 | 試合の計算の変更(指紋のやり直し)。走塁判断の効きが弱いこと、捕手の評価が薄いことへの対応(D-173)。WAR の画面(③b)の後 |
| 利用者が式を書いて作る指標(カスタム指標) | M2 の後で検討(D-129) |
| 延長契約(複数年の途中での結び直し)・年俸調停 | F3-2b では作らない(D-244)。必要なら F3-2c の後に相談 |
| FA の補償(人的・金銭)・「愛着」の軸(元の球団への残留のしやすさ) | F3-2c では作らない。設定であとから足せる作り(D-260) |
| 「まとめて自由契約にする」ボタン | 作らない(D-257) |
| FA 権の年数を出身(高卒・大卒など)で変える | D-277。候補として記録 |
| 計算本体が返す長い説明の文(note)の整理(保守) | ② で画面では使わなくなった文(年度の確定・基準値・WAR・球場などの note)。確認用のスクリプトとテストが使っているので残している(D-327) |
| ドラフトの「おすすめ」の印 | 付けない(D-299)。手薄なポジションの印と加入後の序列で判断する |

| 年度の確定を 1 回だけ取り消す | 今は確認の画面の「先に保存する」で対応(D-194)。実装するなら、確定前の状態の写しをメモリに持つ形 |
| 事前運転の短縮(20 年にする、設定で短くできるようにする) | スマホの新規開始の時間の実測を見てから決める(D-228)。PC のブラウザでは既定値 6.4 秒 / 試運転あり 19.6 秒(Issue #68) |
| 球団職員(スカウト・コーチ・監督)。スカウトの「見る目」を職員の能力にする | スカウト評価のずれは球団ごとの値で持てる形にしてある(D-200)。実装時期は F3-1 とお金のルールの後 |
