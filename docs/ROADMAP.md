# 軸2:機能フェーズ(F1〜F4)

## F1:1シーズンの再現
12球団・2リーグで1シーズンを打席単位でシミュレーションし、個人成績と指標を出す(D-015、D-016、D-021)。
指標は3弾に分けて実装する(D-018)。弾への振り分けは「個人の記録だけで計算できるか / リーグ全体の基準値が要るか / 守備・走塁・ポジション補正が要るか」で決める(D-026)。設計は最初から WAR まで見据える。

- **第1弾:基本の打撃・投球指標**
  - 例:打率、出塁率、長打率、OPS、ISO、BABIP、K%、BB%、防御率
- **第2弾:+指標・球場補正**
  - wOBA(重みをリーグ全体の結果から決める)、FIP(FIP 定数をリーグ全体の防御率から決める)
  - +指標:リーグ平均を100として表す指標(例:wRC+、OPS+)
  - 球場補正:球場ごとの打ちやすさ・打ちにくさを差し引く調整
- **第3弾:守備・走塁・WAR**
  - 守備指標、走塁指標、それらをまとめた WAR

日程は、まず同一リーグ内のみ(125試合)で動かし、その後に交流戦を足して143試合にする。クライマックスシリーズは後から追加する(D-021)。

1試合の進行は、両リーグ指名打者制(D-046)、走者の進塁・併殺・犠牲フライ(D-045、D-059)、投手の起用と疲労(D-060)、スタメン・休養(D-061)、試合の形式(D-062)で作る。盗塁・犠打などは後から追加する。
