# 説明ブロックの棚卸し(UI の整理②。D-306〜D-313)

画面にあった説明の文を洗い出し、次の 3 つに分けた一覧です。

- **移した**:用語集(`src/pennant/data/glossary.json`)の項目に短くして移した。表の見出しの title・見出しを押すと出る解説・用語集のページ・新規開始の説明バーは、ここから引く。
- **残した**:読み違いを防ぐ 1 行の注意書きとして画面に残した(D-310)。
- **消した**:重複、または画面を見れば分かるので消した。

「→」の右は、移した先の用語集の項目、または残した 1 行の文です。
