ブラウザでの実行の技術検証

計算本体(選手の生成・1回の打席・1試合)を、このブラウザの中の Python(Pyodide)で動かし、速さとメモリを測ります。サーバーには何も送りません。データは架空のリーグだけです。

1. 測定

「測定」を押すと、Python の起動(2回)、1日分(12試合)、1シーズン相当(858試合)、打席ログの大きさ、圧縮した書き出しの大きさを順に測ります。PC で約1分、スマホでは数分かかることがあります。

2. ファイルの書き出しと読み込み

1試合分の打席ログを、ファイル(圧縮した JSON Lines)として書き出します。書き出したファイルを選んで読み込み、Python 側で読めるかを確かめます。



  
3. テスト用の球団名

  
試しに球団名を入れて、1試合の見出しに使います。この欄の文字は、外部に送られず、ブラウザにも保存されません。測定の結果の文章にも入りません。

  
  
  


  
4. 通信と保存の確認

  
このページが通信した先と、ブラウザの保存領域の状態を表示します(測定の結果にも入ります)。
