# ブラウザでの実行の技術検証(テスト用ページ)

計算本体(`src/pennant/`)を、スマホや PC のブラウザの中の Python で動かし、速さとメモリを測るページです(D-082)。
段階3の方式(ブラウザの中で完結する方式。D-081)が成り立つかを確かめるための、小さな検証用です。本番の画面ではありません。

## しくみ

- **Pyodide(パイオダイド)**:ブラウザの中で Python を動かす仕組みです。配布元(`cdn.jsdelivr.net`)から読み込みます。
- **計算本体はそのまま**:`src/pennant/` のコードと初期データ(架空のデータ)を `pennant.zip` にまとめて、ページが読み込みます。書き換えはしていません。
- **Web Worker**:画面とは別に、裏で計算を進めるブラウザの仕組みです。計算中も画面は固まりません。
- **通信の制限**:ページに「通信してよい先」を書いてあり(Content-Security-Policy)、このページ自身と Pyodide の配布元以外には通信できません。
- **保存しない**:ブラウザの保存領域(localStorage・IndexedDB・Cookie など)には何も書きません。

| ファイル | 役目 |
| --- | --- |
| `index.html` | 画面 |
| `app.js` | 画面の動き(ボタンなど) |
| `worker.js` | 裏で Python を動かす部分 |
| `bench.py` | Python 側の呼び出し役(計算本体を呼ぶ) |
| `../scripts/build_web.py` | 上のファイルと計算本体を `_site/` にまとめる |
| `../.github/workflows/pages.yml` | `_site/` を GitHub Pages に公開する自動処理 |

## 公開の設定(最初の1回だけ)

GitHub Pages(リポジトリの内容を Web ページとして公開する機能)を使います。

1. GitHub でこのリポジトリのページを開きます。
2. 上のほうにある「**Settings**」(歯車のマーク)を押します。
3. 左の一覧から「**Pages**」を押します。
4. 「Build and deployment」の「**Source**」で、「**GitHub Actions**」を選びます(選ぶだけで保存されます)。
5. 上のほうにある「**Actions**」を押します。
6. 左の一覧から「**pages**」を押します。
7. 右のほうにある「**Run workflow**」を押し、出てきた緑の「**Run workflow**」をもう一度押します。
8. 1〜2分待つと、一覧の一番上に緑のチェックが付きます(黄色の丸は実行中です)。
9. 緑のチェックの行を押すと、「deploy」の箱の下に公開先の URL が出ます。
   URL は `https://yuusukekokubu-a11y.github.io/npb-pennant-simulator/` の形です。

この後は、`main` に計算本体やページの変更が取り込まれるたびに、自動で公開し直されます。

## 測定のしかた(スマホ・PC 共通)

1. 公開先の URL を、測りたい端末のブラウザで開きます。
2. 「**測定**」を押します。PC で約1分、スマホでは数分かかることがあります。途中で画面を閉じたり、別のアプリに切り替えたりしないでください。
3. 「測定が終わりました。」と出たら、「**結果をコピー**」を押します。
4. 「2. ファイルの書き出しと読み込み」で、「1試合のログを書き出す」を押し、続けて「ファイルを選んで読み込む」で、いま書き出したファイル(`pennant-game-log.jsonl.gz`)を選びます。「一致の確認:○」と出れば成功です。
5. コピーした文章は、報告 Issue のコメントにそのまま貼ります。

測定の結果の文章には、ブラウザの種類・OS・画面の大きさなどの端末の情報が入ります。名前などの個人の情報は入りません(テスト用の球団名も入りません)。

## 手元での試し方(開発者向け)

```bash
python scripts/build_web.py                       # _site/ を作る
python -m http.server 8000 --directory _site      # http://localhost:8000/ を開く
```

通信のない環境で試すときは、Pyodide を手元に用意して `--pyodide <フォルダ>` を付けて作り、`http://localhost:8000/?pyodide=local` を開きます。
