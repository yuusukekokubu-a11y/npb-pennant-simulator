# ブラウザの画面

計算本体(`src/pennant/`)を、スマホや PC のブラウザの中の Python で動かして遊ぶ画面です(最小のブラウザ画面①②。D-107、D-114)。
公開先:`https://yuusukekokubu-a11y.github.io/npb-pennant-simulator/`

開発者向けの測定ページ(技術検証。D-082)は、`/dev/`(公開先の URL の最後に `dev/` を付けた場所)にあります(D-111)。

## 遊び方(スマホ・PC 共通)

1. 公開先の URL をブラウザで開きます。**初回は約12MBをダウンロードします**(ブラウザの中で計算を動かすための Python 一式)。Wi-Fi をおすすめします。
   - **横画面専用です**(D-495)。スマホ・タブレットは横にして遊びます。縦に持つと「横にしてください」の案内だけが出ます(横にすれば、そのまま続きから遊べます)。PC は窓の形に関係なく遊べます。
   - **ホーム画面に置くと、アプリのように開けます**(PWA。D-496)。Android の Chrome はメニューの「ホーム画面に追加」(または「アプリをインストール」)、iPhone の Safari は共有のボタンの「ホーム画面に追加」。Android では、ホーム画面から開くと全画面で横に固定されます。iPhone は向きが固定されないので、横にして遊んでください。ホーム画面から開いても、通信のない場所では動きません(Python 一式を配布元から読むため)。
   - 横持ちのスマホでは、タブが画面の左の縦の列になります(D-497)。
2. 「**新しく始める**」を押し、12球団の名前を入れます。設定の項目(名前の欄・選択肢)を選ぶと、その説明が画面の下のバーに 1〜2 行で出ます(選び直すと入れ替わり、画面を離れると消えます。D-313)。空欄のままなら、薄く表示されている架空の名前になります。名前に問題があると、欄の下に赤い字で理由が出ます。
3. 「**自球団にする**」で、応援する球団を1つ選び、「**この内容で始める**」を押します。始める前に、リーグの歴史(数十年分の選手の入れ替わり。試合はしません)を作ってから、画面に出ない練習のシーズン(試運転)を1回回して、wOBA などの指標の基準値(重み・リーグ平均)を求めます。スマホで数秒かかり、「リーグの基準値を求めています」と進み具合が出ます。急ぐときは、「詳しい設定」で「既定値を使う(速い)」を選べます。
4. 「進行」のタブで、「**1日**」「**1週間**」「**最後まで**」を押して進めます。0.6 秒より長くかかるときだけ「**止める**」が出ます。押すと、その日の試合が終わったところで止まります。直近の日の全試合のスコアも出て、押すと試合のページを開きます。
5. 「順位表」のタブで、リーグを切り替えて順位を見ます。★と色の付いた行が自球団です。チーム名を押すと、チームのページ(成績と選手の一覧)を開きます。チームのページの「本拠地」を押すと、球場のページ(本拠地での試合数・本塁打・得点と、本拠地とアウェイの比較の表)を開きます。球場ごとに本塁打や安打の出やすさ(真の倍率)が違いますが、ふだんは隠れています。2シーズン目からは、前のシーズンまでの結果から推定した球場補正(得点は本塁打と BABIP の推定から組み立てた値。BABIP 単独は参考値)が球場のページに出ます(1シーズン目は「まだ推定できません」)。答え合わせモードをオンにすると、真の倍率も見られます。試合のページにも球場名が出ます。
6. 「成績」のタブで、個人成績を見ます。打者/投手、「基本」「セイバー」「能力」を切り替えられます。列の見出しを押すと並べ替わります(もう一度で逆順)。見出しに指を重ねる(PC ではマウスを重ねる)と、用語集の解説が出ます。表の上の「並び順」の欄からも、すべての指標(基本・セイバー)を選べ、「高い順/低い順」で向きを変えられます。並び順と絞り込みは、「基本」「セイバー」「能力」を切り替えても保たれます。並び順に使っている指標が切り替えた先の表にないときは、名前の隣に固定して出します(例:打率の高い順のまま「セイバー」を見ると、名前の隣に打率が出ます)。打者と投手を切り替えたときは、その側の既定の並び順(打者は打率、投手は防御率)に戻ります。「規定到達者だけ」(規定打席・規定投球回に届いた選手だけ)は、最初はオンです。選手名を押すと、選手のページ(通算と試合ごとの成績)を開きます。
7. 「試合」のタブで、日付を選んでその日の試合を見ます。試合を押すと、試合の流れ(1打席ずつの文章)と投手の成績が出ます。
8. 「成績」の「WAR」には、選手が控え水準の選手に比べて何勝分多く勝ちに貢献したか(野手は打撃・走塁・守備・ポジション補正・控え水準の内訳つき。投手は失点版と FIP 版)が出ます。選手のページとチームのページにも出ます。シーズン途中は「シーズン途中の値(ここまで)」と 1 行出ます。用語の解説は、メニューの用語集にあります。
9. 「成績」の「セイバー」には、wOBA・wRC+・OPS+(打者)と FIP(投手)も出ます。基準値と球場補正の考え方は、メニューの用語集(「基準値」「球場補正」)にあります。
10. 上の「**メニュー**」の下の方の「**用語集を見る**」で、指標・契約とお金・ドラフトとスカウト・試合と球場・画面の見方の用語(式・良い向き・ゲームのルールも)を読めます。上の欄で分類を選び、検索の欄に略語(例:wRC)や日本語(例:年俸)を入れて探せます(UI の整理②。D-307)。画面には説明の文を置かず、読み違いを防ぐ 1 行の注意書きだけを出します。メニューでは、答え合わせモードも選べます(最初はオフ)。オンにすると、「能力」で選手の本当の実力(20〜80 の数値)が見られます。成績から実力を推理する楽しみが減るので、見たいときだけオンにしてください。この設定は保存されず、ページを開き直すとオフに戻ります。
11. 新規開始で「自球団にする」を選ぶと、その球団の GM としてオフの手続き(契約・FA・ドラフト・市場)を自分で進められます。選ばなければ観戦のみで、手続きは自動で進みます。「詳しい設定」で、スカウト評価のずれの大きさ(小・中・大)を選べます。
12. シーズンが終わると、「進行」のタブに「**年度を確定する…**」が出ます。確認の画面で「年度を確定する」を押すと、今シーズンの成績を履歴に残し、選手の年齢が1つ進んで能力が更新され、引退する選手と入団する新人が決まり、次のシーズンが始まります(**この操作は戻せません**。直前の状態を残したいときは、確認の画面の「先に保存する」で別のファイルに保存してください)。確定のあとに「オフの結果」(引退した選手・入団した新人)が出ます。答え合わせモードがオンのときは、残った選手の能力の増減も出ます。2シーズン目からは、「成績」の表の上でシーズン(今シーズン・過去の各シーズン・通算)を選べ、選手のページに年度別の成績が出ます。球場補正も、前のシーズンまでの結果から推定した値になります。
13. 操作する球団があるときは、年度の確定のあとに「**オフの手続き**」の画面になります(UI の整理①a。D-270〜D-273)。上に段階のタブ(**契約・FA・ドラフト・市場・完了**)と、状態バー(今の段階の要約・総年俸・ボタン)が出ます。ボタンは 2 種類:「**この段階をおまかせ**」は今の段階だけを AI と同じ方針で(自分の球団の分も)進め、AI が何をしたかの一覧(「おまかせの結果」)を出して次の段階の入口で止まります。「**次の手続きへ**」は自分の操作を終えて進みます(AI は代わりに何もしません。FA では残りのラウンドで提示せず、ドラフト・市場では残りの自分の番をパス)。残りを全部 AI に任せるときは、上の「メニュー」の「**全部おまかせ**」(確認つき。やり直せないので、先に保存しておくと安心です)。ドラフトと市場の画面は下の 13-7 を見てください。完了で 70 人に満たない分は自動補充。ドラフト候補は、自球団のスカウトの評価(A〜E)と一言(目立つ長所 1〜2 個)だけが見え、本当の能力とは少しずれています(入団すると能力が見えます)。途中で保存して後から再開できます。
13-1. 「進行」の「**スタメンと打順**」(自球団があり、シーズン中だけ。D-373):打順の型(二番強打者・二番つなぎ役・機動力重視・長打重視)を選ぶと、AI がその型でスタメンと打順を組みます。打順ごとに守備位置と選手を選んで「このスタメンと打順にする」を押すと、次の見直し(7 日ごと)まで毎試合その打順で戦います(見直しの日に AI が型で組み直します)。本来と違う守備位置に入れた選手は守備の能力が下がります(近いポジションは −5、遠いポジションは −10)。「AI に組ませる」で、今の型の AI の打順に戻ります。
13-2. 「進行」の「**ドラフトの振り返り**」(チームのページにもあります)で、入団した年度と球団を選ぶと、入団した選手の経路(ドラフトの巡(抽選なら印)・市場・自動補充)、入団時の評価(A〜E)とスカウトの一言、今の所属、出場と WAR の累計が 1 人 1 行で出ます。数年進めてから見ると、当たり外れが分かります。
13-3. PC のブラウザや、幅の広いスマホ・タブレットの横持ち(幅 900 px 以上)では、契約・FA・ドラフト・市場・ドラフトの振り返りの表が横スクロールなしで全列出ます。それより狭いときは、左端の名前と並べ替えた列を固定して横にずらします。
13-4. **資金と年俸**(作り直し②):各球団は「**資金**」(年俸の合計に使える上限)を持ちます。球団の規模(大・中・小)で 48 億・40 億・32 億円から始まり、毎年のオフに前のシーズンの順位で少し増減します。選手のページに年俸(架空の「万円」)・契約年数・残り年数・年俸の履歴が、チームのページに総年俸・資金・使用率と年俸の高い順の表が出ます。年俸は見える情報(直近 3 シーズンの WAR と、見せる能力)だけから査定します。総年俸が資金を超えると、自由契約で減らすまで「次の手続きへ」が押せません(FA では資金を超える提示はできず、市場では資金を超える選手は希望できません)。
13-5. **契約**(契約更改と自由契約をまとめた画面。D-272、D-358):契約が満了した選手は、オフの手続きの始めに査定で自動的に更改されています(選手は受けます。1 年で下がるのは前の年俸の 25% まで。主力級は 2〜3 年契約)。自球団の全選手が 1 つの表に出ます(列:名前・WAR・状態・新しい年俸・増減・ポジション・年齢・今の契約・出場)。初期は WAR の低い順(手放す候補が上)。見出しをタップすると並べ替え、もう一度で逆順。絞り込みはポジション(全員・投手・捕手・内野手・外野手)と状態(更改済・FA 宣言・自由契約・契約中)。投手・捕手・内野手・外野手を選ぶと、成績の種類(基本・セイバー・WAR)も選べます。選手をタップするとパネルが開き、更改の結果(前の年俸 → 新しい年俸)を確かめて、「**自由契約にする**」で手放せます(複数年契約の途中の選手も。残りの契約は消えます)。総年俸が資金以下なら「次の手続きへ」が押せます。AI 球団の資金の超過の解消と自由契約は、この段階の終わりに行われます。
13-6. **FA**(F3-2c):一軍に登録されたシーズン(各シーズンの開幕時の一軍 29 人)が 7 シーズンに達した選手は **FA 権**(フリーエージェント:他球団と自由に契約できる権利)を持ちます。年数は選手のページの「FA 権」に出ます。契約が満了した FA 権保持者は、一部が **FA 宣言**して球団を離れます(見込みの WAR が高いほど宣言しやすい。止められません。年数は 0 に戻ります)。契約の段階のあとが「FA」の段階で、宣言した全選手の表(ポジション・年齢・前の所属・成績・算定年俸・状態)が出ます。名前を押すと提示のパネルが開き、年数(1〜5 年)と年俸(±% のボタンあり)を決めて「提示する」。何人にでも出せます(空き枠と資金の範囲)。状態バーの「ラウンド N を締める」で AI 球団の提示と合わせて選手が 1 つを選び、結果が出ます。選手は金額を中心に、年数・出場機会・勝てるチームも考えて選びます(元の球団の提示は少しだけ有利:愛着)。これを 3 ラウンド行い、決まらなかった選手は自由契約市場へ回ります。補償はありません。「次の手続きへ」を押すと、自分は提示せずに残りのラウンドを締めます(「この段階をおまかせ」なら AI と同じ方針で提示します)。
13-7. **FA・ドラフト・市場の画面**(UI の整理①b):3 つとも、上は状態バー(要約・総年俸・ボタン)と絞り込みの 1 行だけで、すぐ下が表です。絞り込みは「全員・投手・捕手・内野手・外野手」の 1 本で、投手などを選ぶと成績の種類(基本・セイバー・WAR)も選べます。列見出しを押すと並べ替わり(もう一度で逆順)、並べ替えた列は名前のすぐ右に固定されます。「**加入後の序列**」は、その選手が入ったら自球団の同じポジションで何番手になるか(● は一軍に入る見込み)。状態バーの要約を押すと、**自球団の状況**(ポジション別の人数と目安・主な選手の WAR と年齢・空き枠・資金)が開きます。◆ は自球団の手薄なポジション(人数が目安より 2 人以上少ない、または一軍相当の見込みが下位 4 球団)。**ドラフト**の列は 評価(A〜E)・スカウトの一言・年齢・出身・ポジション・加入後の序列。**1 巡目は入札**:名前を押して「1 巡目に入札する」。全球団が同時に入札し、同じ選手に重なったら抽選です(外れたら、残りの候補からもう一度入札。結果は表の下の「1 巡目の入札の結果」)。2 巡目からは前年の順位が低い球団から順番に指名します(状態バーの「自分の番まで」で他球団の指名を進め、自分の番になったら名前を押して「指名する」。「パス」も状態バー)。**市場**は年俸が自動です(プロの選手は算定、指名されなかった候補は最低年俸。1 年)。手放された選手は能力の総合と成績が、指名されなかった候補(前の所属「候補」)は評価と一言が見られます。名前を押して「獲得を希望する」(入れた順が優先の順)。状態バーの「市場を締める」で、前年の順位が低い球団から 1 人ずつ、希望の選手を獲得します。決まらなかった選手はリーグを去ります。「この段階をおまかせ」は、ドラフトと FA の段階だけ確認が出ます。
14. 上の「**保存**」で、セーブデータ(`save-日付.sav`)がダウンロードされます。**自動では保存しません**。未保存の変更があるときは、上に「● 未保存の変更があります」と出て、ページを閉じようとすると警告が出ます。
15. 続きから遊ぶときは、スタートの画面の「**セーブデータを開く**」か、上の「**開く**」で、保存したファイルを選びます。読み込めないファイルのときは、理由が日本語で出て、今のゲームはそのまま残ります。

新規開始の「**詳しい設定**」では、シード(乱数の出方を決める初期値)を入れられます。同じシードなら、同じ選手・同じ試合結果になります(D-113)。普段は空欄のままで構いません。

### セーブデータの扱い(D-085、D-112)

- セーブデータには、入力した球団名が入ります。**実在の名前を入れたファイルは、ほかの人と共有しないでください**(SNS への投稿や、共有リンクで渡すことも含みます)。
- 個人のクラウド(自分だけが使うクラウドの保存場所)に置いて、スマホと自宅の PC で受け渡すのは構いません。ただし、**作業用の PC に同期のフォルダを作る**(PC にコピーが残る)ことと、**共有リンクを作る**ことは避けてください。
- ページは、入力した名前や進み具合を、ブラウザの保存領域(localStorage・IndexedDB・Cookie など)に書きません。外部にも送りません。

## しくみ

- **Pyodide(パイオダイド)**:ブラウザの中で Python を動かす仕組みです。配布元(`cdn.jsdelivr.net`)から読み込みます。
- **計算本体はそのまま**:`src/pennant/` のコードと初期データ(架空のデータ)を `pennant.zip` にまとめて、ページが読み込みます。書き換えはしていません。
- **Web Worker**:画面とは別に、裏で計算を進めるブラウザの仕組みです。計算中も画面は固まりません。
- **通信の制限**:ページに「通信してよい先」を書いてあり(Content-Security-Policy)、このページ自身と Pyodide の配布元以外には通信できません。
- **能力値は出さない**:答え合わせモードがオフのときは、画面と通信に、選手の公開用の情報だけを使います。能力は、オンのときだけ、答え合わせ用の入口から受け取ります(D-108、D-114)。

## 公開の設定(最初の1回だけ。設定済み)

GitHub Pages(リポジトリの内容を Web ページとして公開する機能)を使います。

1. GitHub でこのリポジトリのページを開きます。
2. 上のほうにある「**Settings**」(歯車のマーク)を押します。
3. 左の一覧から「**Pages**」を押します。
4. 「Build and deployment」の「**Source**」で、「**GitHub Actions**」を選びます(選ぶだけで保存されます)。
5. 上のほうにある「**Actions**」を押します。
6. 左の一覧から「**pages**」を押します。
7. 右のほうにある「**Run workflow**」を押し、出てきた緑の「**Run workflow**」をもう一度押します。
8. 1〜2分待つと、一覧の一番上に緑のチェックが付きます(黄色の丸は実行中です)。

この後は、`main` に計算本体やページの変更が取り込まれるたびに、自動で公開し直されます。

## 測定ページ(開発者向け。`/dev/`)

1. 公開先の URL の最後に `dev/` を付けて開きます。
2. 「**測定**」を押すと、Python の起動・1日分・1シーズン・集計・保存の速さとメモリを測ります。PC で約1分、スマホでは数分かかります。
3. 「**指紋を確かめる**」で、結果の指紋(同じシードなら、どの端末でも同じになるはずの値)を計算します。PC の `python scripts/fingerprint.py` と見比べます。
4. 結果の文章は「結果をコピー」でコピーし、報告 Issue のコメントに貼ります。名前などの個人の情報は入りません。

## 手元での試し方(開発者向け)

```bash
python scripts/build_web.py                       # _site/ を作る
python -m http.server 8000 --directory _site      # http://localhost:8000/ を開く(測定ページは /dev/)
```

通信のない環境で試すときは、Pyodide を手元に用意して `--pyodide <フォルダ>` を付けて作り、`http://localhost:8000/?pyodide=local` を開きます。

ブラウザでの通しの確認(Playwright という、ブラウザを自動で操作する道具が必要):

```bash
node scripts/check_browser.mjs http://127.0.0.1:8000/?pyodide=local
```
