# npb-pennant-simulator

プロ野球(NPB)のペナントレース(シーズン全体の順位争い)をシミュレーションする Python プロジェクトです。

> **現在は開発中です。**
> 計算本体(選手の生成・1回の打席・1試合)ができた段階で、操作画面はまだありません。
> 今後の予定は [docs/ROADMAP.md](docs/ROADMAP.md) を参照してください。

## ⚠️ 注意:実名入りのセーブデータは公開しないでください

- このリポジトリには、**架空の球団・選手のデータのみ**を置いています。実在の球団名・選手名・ロゴ・成績データは含みません。
- 球団名などはユーザーが自分で入力し、その内容は「セーブデータ」として**各自のPCの中(リポジトリの外)**に保存される設計です。
- **実名を入力したセーブデータを、GitHub などで公開・共有しないでください。**
  (`.gitignore` でもセーブデータは除外していますが、手動でのアップロード等にもご注意ください)

### 実名入りのデータを扱うときの注意(D-085)

このアプリは、サーバーを使わず、ブラウザの中だけで動きます(D-081)。データの管理は、使う人自身が行います。
遊ぶための画面は `https://yuusukekokubu-a11y.github.io/npb-pennant-simulator/` です(使い方は `web/README.md`)。

- **個人のクラウドに保存するのは、かまいません。** スマホと自宅 PC の間の受け渡しにも使えます(OneDrive・iCloud Drive・Google ドライブなど)。
- **作業用 PC には、クラウドの同期のフォルダを作らないでください。** 同期のフォルダとは、自動で他の端末と中身をそろえるフォルダのことで、作るとその PC にコピーが残ります。
- **共有リンクを作らないでください。** リンクを知っている人なら、誰でも開けてしまいます。
- **2台で同時に開かないでください。** 古いほうで保存すると、新しい内容を上書きしてしまいます。
- **ダウンロードフォルダにコピーが残ることがあります。** 書き出したファイルは、置き場所を決めて移し、不要なコピーは消してください。
- **共用の端末では、シークレットウィンドウを使ってください。**
  シークレットウィンドウは、閉じると履歴などが消えるブラウザの窓です。
- **ブラウザのキャッシュに、表示内容が残る可能性があります。**
  キャッシュは、表示を速くするためにブラウザが一時的に保存しておくものです。
- ブラウザ内の自動保存は、既定でオフです。保存は、ファイルの書き出しで行います(D-084)。

## 動作確認(テストの実行)

Python 3.10 以上が必要です。

```bash
pip install -e ".[dev]"   # 開発用の道具(pytest)を入れる
pytest                    # 速いテストを実行する(重いテストは除く)
pytest -m slow            # 重いテストだけを実行する(複数シーズン・複数の世界を回すものなど)
pytest -m ""              # 全部のテストを実行する
```

テストは「速いテスト」と「重いテスト」(印 `slow`)に分けています(D-280)。重いテストのファイルやテストを名前で指定して回すときも、`-m ""` か `-m slow` を付けてください(付けないと除かれます)。

GitHub 上では、CI(自動でテストを走らせる仕組み)が次のように回します(D-279〜D-281)。

| いつ | 何を | Python の版 |
| --- | --- | --- |
| PR を出したとき(出し直すと、古い実行は止まる) | 速いテスト(指紋の一致の確認を含む) | 3.10・3.12・3.14 |
| PR で計算本体(`src/pennant/`・`tests/`・`pyproject.toml` など。`scripts/ci_needs_slow.py`)が変わったとき | 重いテストも | 3.12 |
| main に取り込んだあと | 速いテスト | 3.12 |
| 手動(Actions の画面の「test」→「Run workflow」) | 速いテストと重いテスト | 3.12 |
